# ZIRIN — Dossier MVP V2
Documentation de cadrage pour développer une **maquette interactive**, pas le produit final.

## Décisions
- React + Vite + TypeScript + Tailwind CSS
- 20 devinettes, 15 contes (corpus à rédiger et vérifier)
- Données JSON, pas de backend ni d'authentification
- Mobile-first, palette orange/marron/ivoire provisoire
- Dock avec stickman animé
- Formulaire Contact/Suggestions visuel uniquement
- Envoi de courriels via un service tiers : post-MVP, fournisseur à confirmer
