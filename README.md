# ZIRIN — Dossier MVP V2
Documentation de cadrage pour développer une **maquette interactive**, pas le produit final.

## Décisions
- React + Vite + TypeScript + Tailwind CSS
- 20 devinettes, 15 contes (corpus local disponible, vérification éditoriale à poursuivre)
- Données JSON, pas de backend ni d'authentification
- Mobile-first, palette orange/marron/ivoire provisoire
- Dock avec stickman animé
- Formulaire Contact/Suggestions visuel uniquement
- Envoi de courriels via un service tiers : post-MVP, fournisseur à confirmer

## Ordre de lecture agent
1. CAHIER_DES_CHARGES.md
2. DESIGN_SYSTEM.md
3. ROADMAP.md
4. ARCHITECTURE.md
5. RULES.md
6. TODO.md
7. AGENT.md
8. CHANGELOG.md

Le corpus de 15 contes est intégré dans `src/data/zirin-contes-15-corrige.json` et sert le catalogue ainsi que les pages de lecture. Les récits sont signalés comme des créations contemporaines inspirées, sans provenance traditionnelle revendiquée. Le corpus de 20 devinettes et la validation finale des contenus restent à faire.
